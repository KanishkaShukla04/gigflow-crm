# GigFlow CRM

Full-stack CRM application built with:

- React
- TypeScript
- Tailwind CSS
- Node.js
- Express
- MongoDB

## Features

- JWT Authentication
- Role-based Access
- CRUD Leads
- Charts & Analytics
- Debounced Search
- Filters
- Pagination
- CSV Export
- Dark Mode
- Docker Support

## Run Client

cd client
npm install
npm run dev

## Run Server

cd server
npm install
npm run dev
