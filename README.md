# GigFlow CRM

Full-stack CRM application built with:

- React
- TypeScript
- Tailwind CSS
- Node.js
- Express
- MongoDB

## Features

- JWT Authentication
- Admin & Sales Roles
- Lead CRUD
- Search & Filters
- Pagination
- Charts & Analytics
- Dark Mode
- Protected Routes

## Run Client

cd client
npm install
npm run dev

## Run Server

cd server
npm install
npm run dev
